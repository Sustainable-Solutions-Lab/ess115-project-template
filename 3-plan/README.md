# Phase 3: Research plan

**What goes here:** a plan specific enough that a different group can carry it out.

Put your deliverable in this folder as `plan.md` (or a PDF). It should cover:

- The question, as it now stands.
- **Data:** each dataset by name, with a link, what it measures, its units, its coverage, and proof that you could open it (a few rows, or a screenshot).
- **Methods:** the steps from raw data to answer, in order. Name the calculation, not just the topic.
- **Expected result:** a back-of-envelope estimate of the answer, and a sketch of the main figure.
- **Risks:** what could go wrong, and the fallback if it does.
- **Division of work** for the next group, with rough time estimates.

A TA checks every plan for feasibility before it is handed off.
