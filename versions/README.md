# Frozen versions of the example story

Each folder is a working copy of the story as it stood at one git tag, with only the files the page needs. `compare.html` (one level up) shows any two side by side. `versions.json` lists them for its menus.

To add one after tagging a new version: copy `index.html`, `story.md`, `css/`, `js/`, `images/` and the charts and data the story uses into `versions/<tag>/`, and add a line to `versions.json`.

Students: delete this folder, `compare.html` and `log-snapshots/` when you start your own project.
