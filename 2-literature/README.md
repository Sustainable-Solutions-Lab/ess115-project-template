# Phase 2: Literature review

**What goes here:** a map of what is already known about the question, and what is not.

Put your deliverable in this folder as `literature-review.md` (or a PDF), plus:

- `sources.csv`: one row per source, with columns `citation, link, type, what_it_found, how_we_used_it`.
- Any key papers you are allowed to share, or links to them.

The review should end with a short list of **gaps**: the specific things nobody has measured or compared yet. The next group builds its research plan on those gaps.

If you changed or sharpened the question you received, say so at the top and explain why.
